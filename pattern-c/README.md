# パターンC：インライン診断型セルフチェックLP

Squad Beyond の4ペインにそのまま貼れる構成です（現行LPと同じ形式）。

| ファイル | 貼り付け先 |
|---|---|
| `1_html.html` | HTML |
| `3_js_head.html` | Javascript Head（**CSSもここに含まれています**） |
| `4_js_body.html` | Javascript Body |
| `2_css.css` | CSSペインは空のままでOK（貼っても二重適用にはなりません） |

Squad Beyond の CSS ペインが反映されないケースがあったため、CSS は `3_js_head.html` 内のスクリプトから `<style>` として差し込んでいます。
`2_css.css` が編集用の元ファイルです。CSSを直したら `python3 build_js_head.py` で `3_js_head.html` を再生成してください（計測タグは `3_js_head.tracking.html`）。

`preview.html` は確認用に結合したものです（`./build_preview.sh` で再生成）。

## 現行LPから変えたこと（CVRへの効き方の大きい順）

1. **タップ数を7回から3回に削減**
   現行は「開始ボタン → Q1 → 次へ → Q2 → 次へ → Q3 → LINE」でした。解説を挟むたびに「次へ」を押させる作りで、毎回離脱のきっかけになっていました。新版はQ1をページ上にそのまま出し、回答すると自動で次の問題へ進みます。解説の内容は「選ばれる3つの理由」として結果の下にまとめました。
2. **Q1で「いいえ」（剥けない）の人はQ2をスキップ**
   この人は判定上、Q2の回答に関係なく真性になります。2問で結果が出ます。
3. **LPが約束していた「治療推奨レベル」をLINE追加の前に見せる**
   現行は「レベルがわかる」と書いておきながら、結果を見せないままLINE追加を求めていました。新版は、タイプ（仮性・カントン・真性）とレベルのメーターをその場で表示し、詳細はLINEで届ける形にしました。先に見返りを渡してから、追加をお願いする流れです。
4. **クーポンを「発行済み」として見せる**
   「受け取らないと失う」状態にして（保有効果）、CTAのすぐ上に置きました。
5. **進捗バー**
   最初から10%進んだ状態で始め、「あと○問」と残りを示します。終わりが見えると途中でやめにくくなります。
6. **追従バーと離脱ポップアップの文言が状態で変わる**
   未回答なら「開始」、回答途中なら「続きから（あと○問）」、結果表示後なら**診断タイプ別のLINE URLへ直接遷移**します。現行は結果を見た後でも「セルフチェックを開始」のままで、LINEに行けませんでした。
7. **LINEから戻ってきた人には結果を再表示**（sessionStorage を使用）
8. **LINE追加前の不安を外す**
   CTAの下に「何が届くか」「いつでもブロックできる」と添え、ページ下部にFAQを置きました。FV直下には「無料・匿名OK・3問30秒・写真不要」のチップを置いています。
9. **表示速度**
   FV画像の `lazyload` をやめて `fetchpriority="high"` にしました。使っていなかった Noto Serif JP の読み込みも削除しています。

## 計測

- LINEクリック：既存のXの計測（`twq('event','tw-omfcg-rd72l')`）をそのまま使っています。結果画面のボタン・追従バー・ポップアップの3か所すべてで発火します。
- ファネル分析用に `dataLayer` へイベントを送っています：`mlc_answer_q1/q2/q3`、`mlc_result_view`、`mlc_line_click`（`mlc_place`＝result/sticky/exit）、`mlc_start_click`、`mlc_exit_popup`。GTMを入れればそのまま使えます。入れていなくても害はありません。

## 公開前に確認してほしいこと

- **医療広告ガイドライン**：結果は「〜の可能性」「目安」と表現し、注記で医師の診察が必要だと明記しています。体験談、ビフォーアフター、架空の期限・人数は入れていません。
- 「写真不要」「匿名OK」：このセルフチェックは名前も写真も求めないので事実ですが、LINE側の運用と食い違いがないか確認してください。
- 「選ばれる3つの理由」の画像：既存の解説画像（7130693 / 7130726 / 7130762）を、元の解説文と同じ文脈になるように配置しました。中身が合っているか確認してください。
- Promolayer のポップアップを使っている場合、自前の離脱ポップアップと二重に出ないか確認してください。
