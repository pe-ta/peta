# パターンD：1タップ・タイプ選択LP（読み物型）

パターンC（3問のセルフチェック）とはまったく違う考え方のLPです。ABテストで比べるために作りました。

| | パターンC | パターンD |
|---|---|---|
| 考え方 | 診断で関心を高めてから、結果を見せてLINEへ | **診断はしない**。自分でタイプを選ぶだけでLINEへ |
| LINEまでのタップ数 | 3〜4回 | **2回**（タイプを選ぶ → LINE） |
| 一番の訴求 | 治療推奨レベル（結果） | **価格（99,000円→45,000円）**とプライバシー |
| デザイン | 明るい青・ポップ | 紺×ゴールド・落ち着いた男性向け |
| FV | 既存のFV画像 | **HTMLのテキストFV**（読み込みが速く、文言のテストもしやすい） |

## 構成

1. **FV**：「包茎の相談はLINEでこっそり。」というコピー、クーポン価格、「1タップ・名前写真不要・全員男性」
2. **タイプ選択**：A 仮性／B カントン／C 真性／? わからない。選ぶとその場にパネルが開き、タイプ別の一言とLINEボタンが出ます
3. **よくある3つの不安**：費用／人に知られたくない／仕上がり（既存の解説文と画像を再利用）
4. **LINE追加後の流れ**：受け取るだけで受診の必要はない、と伝えて心理的なハードルを下げます
5. **追従バー・離脱ポップアップ**：タイプを選ぶ前は「タイプ選択へ」、選んだ後はそのタイプのLINEへ直接移動します

## 計測

- LINEクリック：Xの計測 `twq('event','tw-omfcg-rd72l')` を使っています
- `dataLayer`：`mld_type_select`（`mld_type`）、`mld_line_click`（`mld_place`＝panel/sticky/exit）、`mld_go_select`、`mld_exit_popup`

## 公開前に確認してほしいこと

- **価格表示**：FV画像の表記（99,000円→45,000円（税込）※スタンダードカットに適用）をそのまま使っています。二重価格表示として問題ないか確認してください。
- **「タイプ別の情報」がLINEで届くか**：パネル内の説明が実際の配信内容と合っているか確認してください。
- **「わからない」の振り分け先**：今は仮性オファーに送っています。専用の導線があれば差し替えてください。
