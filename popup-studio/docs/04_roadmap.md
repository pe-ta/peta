## Phase 1: MVP（8〜10 週間）

スプリント構成（2 週間 × 4〜5）:

1. **S1 基盤**: データモデル、認証、テンプレートエンジン（HTML/CSS → PNG）、1 テンプレート
2. **S2 生成**: 構造化ブリーフ、LP 抽出、コピー生成、GIF 描画、ジョブキュー
3. **S3 プリフライト + 監修**: 仕様/可読性/ブランド/表現チェック、比較ビュー、簡易エディタ、自己批評ループ
4. **S4 承認ポータル**: 実機プレビュー、注釈、承認/差戻し（理由タグ）、リマインド、書き出し
5. **S5 パイロット**: AP 2 名 × クライアント 3 社で実運用。初稿到達時間・一発承認率・AP 単独完結率を計測

Exit 基準: 初稿到達 ≤ 2 時間、一発承認率 ≥ 50%（目標 60%）、パイロット案件のリードタイム ≤ 7 営業日。

## Phase 2: 計測連携（6〜8 週間）

- 成果データ取り込み（CSV → API）、クリエイティブ ID 突合
- 変種比較ダッシュボード、ベイズ判定ルール、タイムボックス
- ガードレール承認（契約面が許す場合）
- 結果レポート自動生成（クライアント向け）

Exit 基準: 同時検証数 ≥ 3 / クライアント、判定までの日数が直列検証比で半減、North Star（週あたり結論の出た仮説数）が 2x 以上。

## Phase 3: 学習と最適化（8 週間〜）

- DNA タグ × 成果の集計、推奨エンジン、類似ブリーフ検索
- ペアワイズ比較判定（MLLM）と実績校正。相関が閾値を超えたら本番表示
- Thompson Sampling による配信比率制御（配信基盤対応時）
- 翻案生成（勝ち構造の横展開）
- PUSH 配信バナー・ボットシナリオへの拡張検討

Exit 基準: North Star 3x 達成、推奨採用時の CVR リフトが有意、事前スコアと実績順位の相関が確認できる。

| --- | --- | --- |

## 早期に潰すべき技術リスク（Phase 1 S1〜S2 で PoC）

1. GIF の容量と画質が ZEALS 仕様内に収まるか（フレーム数・パレット・ディザの組み合わせ）
2. LP 抽出の精度（ブランド色・ロゴ・訴求点の自動抽出が初期値として使えるか）
3. 画像生成の権利・品質（医療・美容系の表現制約下で使える背景が出るか）
4. 自己批評ループで可読性の指摘がどこまで自動修正できるか
