対象: v0.4 実績構造版（テンプレート・フック・辛口分析・過去案ライブラリ）。

## 2. E2E の結果（ローカル本番ビルド、メモリストア、ルールベース生成）

| スクリプト | 内容 | 結果 |

描画の目視: 7 フック × 3 動きの 21 案で、静止 PNG に指カーソル・点灯状態が混入しないこと、吹き出し・バッジ・ボタン対の重なりが無いことを確認。

## 3. 残っている弱点

1. **写真ビジュアルの実写確認が未了。** この環境では外部画像を取得できないため、本番（Vercel）で OG 画像のある LP を使って確認が必要。
2. **OCR 由来の文言は誤字を含む。** 類似案は「参考」表示に留め、コピー生成では「文言はコピーしない」と指示しているが、プロンプトに誤字が混じる。PaddleOCR-VL への置き換えで改善見込み（`docs/08_research_2026.md`）。
3. **コピー生成と辛口分析の質は API キー次第。** 本番は未設定のためルールベース。
4. **PC サイズ（1040×1040）は暫定。** 実績がほぼ無いため、要望があれば実物に合わせる。
5. **学びログの DNA 集計 UI は未実装。** タグは保存されているが、タグ別勝率の表は実績データ受領後に作る。
