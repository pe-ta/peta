## 4. 残っている弱点

1. 配信基盤との自動連携は、基盤側の書き出し仕様が未確認のため未接続。
2. 本番の `REVIEW_SECRET` が未設定だと、承認リンクが偽造でき、結果 API は無効のまま。Vercel での設定が必要。
3. 写真素材の置き場が無く、写真セルは LP の OG 画像か URL 入力に限られる。全面写真型の実写は本番で要確認。
4. 生成 AI のキーが未設定のため、文言生成と辛口分析はルールベース。
