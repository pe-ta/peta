# 07. 過去ポップアップ 棚卸しレポート（第 1 回）

対象: 共有ドライブ「ZEALS過去クリエイティブ格納フォルダ」から共有いただいたポップアップ 1,195 件（Drive リンク）。
作成日: 2026-10-15。取り込み・解析スクリプトは `popup-studio/tools/inventory/` に格納。

## 0. 結論（先に 5 行）

1. **納品仕様は 900×1265 px の縦型 1 種にほぼ統一**（取り込めた 1,066 件中 957 件 = 90%）。現在の Popup Lab の 640×800 / 800×500 は実態と合っていない。
2. **構造は「質問 + 2 択ボタン」が標準**。オファー + CTA 1 本のバナー型はごく少数。左に否定（いいえ／また今度）、右に肯定（はい／診断する）を置く「はい・いいえ型」が主流。
3. **フック（切り口）は 7 系統に収れん**: 相性診断、招待状、悩み共感、キャンペーン特典、クイズ、二択タイプ診断、価格知りたい。
4. **GIF は約 24%**。その半数弱は 2 フレームの点滅（ボタン・帯を交互表示）、残りはカーソルやキラキラ等の多フレーム。平均 2 秒ループ。
5. ファイル名に `アンカリング向け` `ゲイン・フレーミング` `損得回避バイアス向け` 等の行動経済学タグが既に使われており、DNA タグ体系の下地になる。

→ 第 2 回（ライブラリ化）では、テンプレートを **900×1265・2 ボタン構造** に全面的に作り替え、フック 7 系統 × ビジュアル 3 系統を挑戦者生成の軸にする。

## 1. 取り込み結果

| 項目 | 件数 |
|---|---|
| 共有リンク | 1,195 |
| 取り込み成功 | 1,069（89%） |
| 未取得: Drive 側で見つからない | 約 90 |
| 未取得: 10MB 超（API 上限） | 13 |
| 未取得: 転送上限超過（6.5〜10MB の GIF） | 22 |

未取得のうち転送上限超過分は Drive 連携では取得できない。必要なら zip で別途受け取る。「見つからない」約 90 件は共有ドライブ側で権限が付いていないか削除済みと見られる。

## 3. 構造（レイアウト）

目視（12 クラスタ × 各 30 枚の代表サンプル = 約 360 枚）と OCR による位置解析から、ほぼ全件が次の 5 段構造に収まる。

```
┌──────────────────────┐
│ 帯（アイブロウ）      │  LINEで無料診断！ / 招待状が届きました / かんたん30秒
│ 質問見出し            │  〜との相性をチェックしませんか？
│ ビジュアル            │  イラスト人物 / 写真人物 / 商品 / キャラクター
│ 小バッジ              │  LINEで簡単30秒 / 無料
│ [いいえ] [はい]       │  左: 否定（グレー）  右: 肯定（ブランド色 or 赤・オレンジ）
└──────────────────────┘
```

バリエーション:

- **2 ボタン（主流）**: はい／いいえ、気になる／やってみる、また今度／知りたい、また今度／診断する。
- **CTA 1 本**: 「友だち追加してチェックする」「診断スタート」など。ファイル名に `cta1つ` と明記されるほど少数派。
- **多択（3 択）**: 「学校や仕事との両立／モチベーションの維持」「30 分／1 時間／2 時間」。会話の最初の質問をそのまま置く型。
- **二択タイプ診断**: 「体験型 vs 積み上げ型」「毛穴 vs 皮脂」をボタン自体に置く。

ビジュアルの様式は 3 系統: フラットなイラスト人物（約半数）、写真（人物・商品、約 3 分の 1）、マスコット・キャラクター（残り）。背景は白地 + 上部カラー帯が最多で、次にブランド色のベタ背景、円形フレーム写真。

## 4. フック（切り口）の分類

| フック | 代表コピー | 典型クライアント |
|---|---|---|
| 相性診断 | 「◯◯との相性をチェックしませんか？」 | 塾・保険・スクール・証券 |
| 招待状 | 「◯◯から招待状が届きました」 | 銀行・証券・不動産 |
| 悩み共感 | 「脱毛したのに、また毛が生えてきた…」「将来のお金に不安を感じている方へ」 | 美容医療・金融 |
| キャンペーン特典 | 「現金プレゼントキャンペーン実施中」「0 円体験」 | 銀行・ジム・ヨガ |
| クイズ | 「最大何%OFF で受けられるでしょうか？」 | 美容医療・フィットネス |
| 二択タイプ診断 | 「お子様はどっち？ 体験型／積み上げ型」 | 塾・化粧品 |
| 価格知りたい | 「結局スーツって、いくらかかるの？」「いくらで売れるか」 | アパレル・不動産 |

OCR による自動分類の分布は 5 章を参照。

## 5. コピーコーパス（OCR）

取り込めた 1,068 件を EasyOCR（日本語モデル）で読み取り、位置から帯・見出し・バッジ・ボタンを切り出した。OCR 誤認（「また今慶」「30秘」等）は辞書で補正しているが、残る誤字はある。

### 5.1 構造の分布（OCR による自動判定）

| 構造 | 件数 | 比率 |
|---|---|---|
| 2 ボタン（否定 + 肯定） | 632 | 59% |
| CTA 1 本 | 276 | 26% |
| 多択（2〜3 選択肢） | 70 | 7% |
| ボタン未検出（画像化された文字など） | 90 | 8% |

### 5.2 ボタン対の上位

| 否定 / 肯定 | 件数 |
|---|---|
| いいえ / はい | 503 |
| また今度 / 気になる | 35 |
| また今度 / 診断する | 30 |
| また今度 / チェック（する） | 27 |
| また今度 / 知りたい | 14 |

単語別では「はい」560、「いいえ」536、「また今度」125、「気になる」80、「知りたい」46、「診断する」40、「やってみる」22。肯定ボタンは 2〜5 文字がほぼすべて。

### 5.3 フックの分布（見出し文言による自動分類）

|---|---|
| 相性診断（相性・ぴったり・診断・チェック） | 526 |
| 二択タイプ診断（どっち・どれ・タイプ） | 95 |
| キャンペーン特典（キャンペーン・プレゼント・OFF・円） | 92 |
| 悩み共感（不安・悩み・迷い） | 53 |
| 価格知りたい（いくら・料金・安く） | 46 |

| 判定不能 | 249 |

### 5.4 帯・バッジ

帯は「これが表示された方は」「口座開設を迷っているなら」「かんたん診断」「おトクなキャンペーンは」「あなたに合った」のように、**読み手の条件を名指しする**か**無料・かんたんを示す**かの 2 種類に大別される。バッジは「LINEで（かんたん／無料）」「無料チェック」「カンタン5問」が主。

コーパスは `popup-studio/data/library.json`（757 件、テキストのみ）として Popup Lab に同梱し、「過去の類似案」とコピー生成の参考例に使っている。

## 6. ファイル名から読み取れる制作慣行

- 命名規則 `クライアント_案件番号(7桁)_popup_バリエーション`。案件番号は 0000003〜0005041 まであり、時系列の代理指標になる。
- 1 案件あたりの枚数は 1〜2 枚が 7 割。3 枚以上の比較検証は 3 割にとどまる。
- バリエーション名に `アンカリング向け` `ゲイン・フレーミング` `損得回避バイアス向け` `不安訴求型` `丸型／四角` `cta1つ` `yesyes` `動く` が使われており、設計意図を名前で残す運用がある。
- クライアント数 270、案件数 379。上位は三菱UFJ銀行（62 枚）、レジーナクリニック（37）、Rintosull（24）、明光義塾（20）。

## 7. Popup Lab への反映方針（第 2 回の計画）

1. **仕様**: SP 規格を 900×1265 に変更。PC 用は実績がほぼ無いため任意扱いにする。
2. **テンプレート**: 現行 3 種（image-hero / text-bold / coupon）を廃し、実績構造に合わせた 4 種に置き換える。
   - `question-two-button`（はい・いいえ型、主流）
   - `invitation`（招待状型）
   - `campaign-two-button`（特典訴求 + 2 ボタン）
   - `multi-choice`（3 択）
3. **挑戦者生成の軸**: 訴求軸をフック 7 系統に置き換え、ビジュアル軸を「イラスト人物／写真／キャラクター」に、動きを「静止／点滅／カーソル」にする。
4. **コピー生成**: 帯・見出し・バッジ・ボタン対の 4 スロットを OCR コーパスから学習した定型に沿って生成する。ボタン対は実績上位の組み合わせから選ぶ。
5. **辛口分析の基準**: 「質問になっているか」「否定ボタンが逃げ道として自然か」「帯で LINE・無料・30 秒のいずれかを示しているか」を採点項目に追加する。
6. **DNA タグ**: フック・構造・ビジュアル様式・動き・行動経済学タグ（アンカリング／ゲインフレーミング／損失回避）を各案に付与し、学習ログで集計できるようにする。

## 8. 未解決・依頼事項
