# Popup Studio（仮称）— 離脱時ポップアップ検証速度 3x プロジェクト

**ポップアップクリエイティブの「仮説→制作→承認→配信→学習」ループを 3 倍速で回す**ための社内プロダクト。

## 一文で言うと

> アカウントプランナーがブリーフを入力すると、ブランド規約内でポップアップ案（PNG/GIF）が数分で複数生成され、
> 事前スコアリング → クライアント承認ポータル → 配信 → 計測 → 学習ライブラリ、までを一本のループとして回せるツール。
